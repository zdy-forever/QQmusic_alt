# 月下方海

由无数几何方块组成的夜海，在月光下波光粼粼。每个方块都有一首自己的曲子，也可以把电脑里的音乐放到海面上播放。

## 打开

直接双击 `index.html`，用浏览器打开即可。整个页面（包括三维引擎）都在这一个文件里，断网也能运行。

## 操作

| 操作 | 效果 |
| --- | --- |
| 鼠标指向方块 | 方块浮出海面，边缘亮起 |
| 左键点击方块 | 锁定方块，镜头推近特写，闪两下后开始播放 |
| 按住拖动 | 切换到相邻的方块 |
| 点击空白处 / Esc | 退出特写 |
| 观海模式 | 镜头拉远看整片海；特写 10 秒后也会自动进入 |
| 点击月亮（观海模式） | 暂停 / 继续播放；月亮两侧是上一首 / 下一首，下方是进度条 |
| 右上角白色光点 | 展开菜单：歌单导入、全屏（F 键）、退场 |
| 主界面连点月亮三下 | 彩蛋 |

## 导入音乐

在光点菜单里选「歌单导入」，选择音乐文件或整个文件夹，也可以把文件直接拖进页面。

- 支持 mp3、flac、m4a、ogg、wav 等浏览器能播放的格式
- 歌名、歌手、专辑、封面从歌曲文件里读取，读不到时按「歌手 - 歌名」的文件名识别
- 歌词：同名的 `.lrc` 文件，或歌曲里内嵌的歌词
- 封面：歌曲里内嵌的图片，或同一文件夹里的 `cover.jpg`、`folder.jpg`
- 导入的歌会保存在当前浏览器里，下次打开还在

播放导入的歌曲时，会先分析整首歌的节拍，海面的波纹按节拍扩散；场景色调跟随封面的主色变化。

## 文件说明

| 路径 | 说明 |
| --- | --- |
| `index.html` | 可以直接打开的完整页面（由下面的文件生成） |
| `src/sea.body.html` | 页面源文件 |
| `tools/build_offline.py` | 把源文件和三维引擎打包成 `index.html` |
| `vendor/three.min.js` | three.js r128（MIT 许可，见 `vendor/THREE_LICENSE`） |

修改源文件后重新生成：

```bash
cd moon_cube_sea
python3 tools/build_offline.py src/sea.body.html vendor/three.min.js index.html
```
